# Background Clicker

Auto clicker that can click a window even while it's behind others.

**Download:** [Background Clicker.exe](https://github.com/ChaosityYT/auto-clicker/raw/main/Background%20Clicker.exe) (v1.2) - run it and choose *Install*. It updates itself when you open it.

Windows may warn "Windows protected your PC" because the app isn't code-signed: click **More info -> Run anyway**.
